# Editor refinement, local formatting, and installation

- Date: 2026-11-06
- Status: Accepted through explicit user requests and corrections.
- Context: Preserve Canvas's overall interface while improving readability, spacing, useful color, Markdown, and access to developer tools.
- UI decision: Keep rounded rectangles with concentric inner/outer radii. Notes, Compare, and JSON use one scrolling toolbar row with equal 8px insets and 36px desktop controls. Icon-only controls are square, language names are not truncated, and sidebar search text ellipsizes. Keep one sidebar create action. Expose all board tools directly and keep its menus compact. Preserve keyboard focus rings while suppressing pointer-restoration rings.
- Theme decision: Apply the supplied Van Helsing palette to Canvas dark; do not expose a separately named Van Helsing preset. Preserve saved appearance preferences. New defaults are UI 16px and code 15px, with a persistent toolbar code-size selector. Syntax coloring is lexical across the supported grammars, not semantic analysis.
- Notes decision: New notes use conservative Auto language detection, with manual selection available. Markdown Edit/Read panes independently toggle while retaining one visible. The escaped renderer supports common Markdown and simple frontmatter; it is not a full CommonMark implementation.
- Formatting decision: User explicitly approved Prettier as one production dependency. Run selected parsers locally in a worker for JS/TS/HTML/CSS/Markdown/YAML; reuse the lossless JSON formatter. Keep unsupported languages/error input unchanged, reject stale results, and apply one undoable edit with mapped selections. Format is available with Edit open.
- Board fonts decision: User explicitly chose built-in Excalidraw fonts after learning custom Geist board fonts require unsupported internals or a maintained fork/custom IDs. No fork or font-format change. Fix picker layout only.
- Installation decision: Add dependency-free PWA shell caching and sidebar Install app. Hide on reported installation or standalone mode; offer appropriate browser instructions. Do not claim universal installation detection. No forced activation/reload or workspace database access from the worker. Uncached tools still need connectivity.
- Naming decision: User approved JSON instead of Formatter for the mode; retain persisted `formatter` IDs and existing document names. JWT decoding was discussed only, not authorized for implementation.
- Workflow: User requests root orchestration/audit with Sol/Terra/Luna implementation delegates and appropriate effort; specifically Sol 6.1 XHigh for geometry. Root corrects small integration/review findings and records decisions. User authorized this release's commit/push after checks; repository defaults remain no automatic commit/push/deploy.
